# Customer360 Models Directory

This directory stores serialized Scikit-learn pipelines and Joblib artifacts produced by Customer360.

## Artifacts

- `churn_logistic_regression_pipeline.joblib`: Trained Logistic Regression pipeline including ColumnTransformer preprocessor.
- `churn_random_forest_pipeline.joblib`: Trained Random Forest Classifier pipeline including ColumnTransformer preprocessor.
- Cluster and scaler objects generated during interactive sessions.
